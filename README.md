# CPP05 Exceptions

This project introduces exception handling, classes, inheritance, and polymorphism in C++.

## Exercises

- **ex00** — Create a `Bureaucrat` class with a grade system and exceptions for grades that are too high or too low.
- **ex01** — Introduce a `Form` class that bureaucrats can sign, with grade requirements and exceptions for invalid operations.
- **ex02** — Create an abstract `AForm` class and implement three concrete forms.
- **ex03** — Create an `Intern` class that generates forms dynamically based on their names.

## Topics

- Exception handling
- Custom exceptions
- Classes and inheritance
- Abstract classes and pure virtual functions
- Polymorphism
- Dynamic memory allocation
- Factory pattern
